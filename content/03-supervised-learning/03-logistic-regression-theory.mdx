# 一、二分类问题的建模

在回归任务中，目标变量 $y$ 是连续的实数。现在考虑分类任务：给定输入 $\mathbf{x}$，预测其属于两个类别之一，即 $y \in \{0, 1\}$（或 $y \in \{-1, 1\}$）。

## 为什么不能直接用线性回归？

如果我们直接使用 $\hat{y} = \mathbf{w}^T\mathbf{x} + b$ 做分类：

1. **输出范围不对**：$\hat{y}$ 可以是任意实数，但类别标签只有 0 和 1。
2. **概率解释缺失**：我们希望输出一个介于 0 和 1 之间的概率值。
3. **判别能力差**：线性函数的输出对远离决策边界的点过于敏感。

## 逻辑回归的思路

逻辑回归（Logistic Regression）的核心思想是：**将线性函数的输出通过一个 S 形函数映射到 (0, 1) 区间**，得到属于正类的概率：

$$P(y=1 \mid \mathbf{x}) = \sigma(\mathbf{w}^T\mathbf{x} + b) = \sigma(z)$$

其中 $\sigma$ 就是 **Sigmoid 函数**，$z = \mathbf{w}^T\mathbf{x} + b$ 称为 **logit** 或得分值。

# 二、Sigmoid 函数

Sigmoid 函数（也称 Logistic 函数）的数学定义：

$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

## 关键性质

1. **值域**：$\sigma(z) \in (0, 1)$，完美地将任意实数映射为概率。
2. **对称性**：$\sigma(-z) = 1 - \sigma(z)$。即 $P(y=0 \mid \mathbf{x}) = 1 - \sigma(z)$。
3. **中心点**：$\sigma(0) = 0.5$，当 $z = 0$ 时正好处于决策边界。
4. **单调性**：严格单调递增，$z$ 越大，概率越接近 1。
5. **平滑性**：处处可导，适合梯度优化。

## 导数推导

Sigmoid 函数有一个非常优雅的导数形式：

$$\sigma'(z) = \sigma(z) \cdot (1 - \sigma(z))$$

推导过程：

$$\begin{aligned}
\sigma'(z) &= \frac{d}{dz} (1 + e^{-z})^{-1} \\
&= -(1 + e^{-z})^{-2} \cdot (-e^{-z}) \\
&= \frac{e^{-z}}{(1 + e^{-z})^2} \\
&= \frac{1}{1 + e^{-z}} \cdot \frac{e^{-z}}{1 + e^{-z}} \\
&= \sigma(z) \cdot (1 - \sigma(z))
\end{aligned}$$

这个性质在实际计算梯度时非常方便。

```python
import numpy as np
import matplotlib.pyplot as plt

def sigmoid(z):
    """Sigmoid 函数"""
    return 1 / (1 + np.exp(-z))

def sigmoid_derivative(z):
    """Sigmoid 导数（使用 σ'(z) = σ(z)(1-σ(z))）"""
    s = sigmoid(z)
    return s * (1 - s)

# 可视化
z = np.linspace(-7, 7, 200)

fig, axes = plt.subplots(1, 2, figsize=(12, 4))

axes[0].plot(z, sigmoid(z), 'b-', linewidth=2)
axes[0].axhline(y=0.5, color='gray', linestyle='--', alpha=0.7)
axes[0].axvline(x=0, color='gray', linestyle='--', alpha=0.7)
axes[0].set_xlabel('z = wx + b')
axes[0].set_ylabel('σ(z)')
axes[0].set_title('Sigmoid 函数')
axes[0].grid(True, alpha=0.3)

axes[1].plot(z, sigmoid_derivative(z), 'r-', linewidth=2)
axes[1].set_xlabel('z')
axes[1].set_ylabel("σ'(z)")
axes[1].set_title('Sigmoid 导数')
axes[1].grid(True, alpha=0.3)

plt.tight_layout()
plt.show()

# 验证几个关键值
for val in [-5, -1, 0, 1, 5]:
    print(f"σ({val:2d}) = {sigmoid(val):.4f},  σ'({val:2d}) = {sigmoid_derivative(val):.4f}")
```

# 三、决策边界

决策边界是模型从预测类别 0 切换到类别 1 的分界线。

对于二分类，通常的决策规则是：

$$\hat{y} = \begin{cases} 1 & \text{if } P(y=1 \mid \mathbf{x}) \geq 0.5 \\ 0 & \text{otherwise} \end{cases}$$

由于 $\sigma(z) \geq 0.5 \iff z \geq 0$，这等价于：

$$\hat{y} = \begin{cases} 1 & \text{if } \mathbf{w}^T\mathbf{x} + b \geq 0 \\ 0 & \text{otherwise} \end{cases}$$

因此**决策边界是一个线性超平面**：

$$\mathbf{w}^T\mathbf{x} + b = 0$$

逻辑回归虽然输出概率，但本质上是**线性分类器**。对于二维特征，决策边界是一条直线。

# 四、对数几率（Log-Odds）

从 Sigmoid 函数可以反解出 $z$：

$$\sigma(z) = \frac{1}{1 + e^{-z}} = p \quad \Longrightarrow \quad z = \ln\frac{p}{1-p}$$

其中 $\frac{p}{1-p}$ 称为**几率（Odds）**，$\ln\frac{p}{1-p}$ 称为**对数几率（Log-Odds，或 Logit）**。

逻辑回归的含义是：**对数几率是特征的线性函数**：

$$\ln\frac{P(y=1 \mid \mathbf{x})}{P(y=0 \mid \mathbf{x})} = \mathbf{w}^T\mathbf{x} + b$$

这提供了非常直观的解释：
- 当 $\mathbf{w}_j > 0$ 时，特征 $x_j$ 增加会提高正类的几率。
- 当 $\mathbf{w}_j < 0$ 时，特征 $x_j$ 增加会降低正类的几率。
- 权重的大小 $|\mathbf{w}_j|$ 表示该特征对 log-odds 的影响强度。

```python
# 演示：Log-Odds 与概率的关系
p_values = np.array([0.01, 0.1, 0.3, 0.5, 0.7, 0.9, 0.99])
odds = p_values / (1 - p_values)
log_odds = np.log(odds)

for p, o, lo in zip(p_values, odds, log_odds):
    print(f"p={p:.2f}  →  odds={o:.2f}  →  log-odds={lo:.2f}")
```

# 五、二元交叉熵损失

## 从最大似然估计出发

对于单个样本 $(\mathbf{x}, y)$，在逻辑回归模型下，其似然为：

$$P(y \mid \mathbf{x}) = \hat{y}^y \cdot (1 - \hat{y})^{1-y}$$

其中 $\hat{y} = \sigma(\mathbf{w}^T\mathbf{x} + b)$。整个数据集的对数似然：

$$\ell(\mathbf{w}, b) = \sum_{i=1}^{n} \left[ y^{(i)}\log\hat{y}^{(i)} + (1 - y^{(i)})\log(1 - \hat{y}^{(i)}) \right]$$

最大化对数似然等价于最小化其负值，除以样本数 $n$ 得到平均损失：

$$\mathcal{L}_{\text{BCE}} = -\frac{1}{n} \sum_{i=1}^{n} \left[ y^{(i)}\log\hat{y}^{(i)} + (1 - y^{(i)})\log(1 - \hat{y}^{(i)}) \right]$$

这就是**二元交叉熵损失（Binary Cross-Entropy, BCE）**。

## 损失函数的直观理解

```python
def bce_loss(y_true, y_pred):
    """二元交叉熵损失（数值稳定版）"""
    eps = 1e-15  # 防止 log(0)
    y_pred = np.clip(y_pred, eps, 1 - eps)
    return -np.mean(y_true * np.log(y_pred) + (1 - y_true) * np.log(1 - y_pred))

# 展示损失对不同预测的惩罚
y_true = 1
preds = np.linspace(0.01, 0.99, 50)
losses = [bce_loss(np.array([y_true]), np.array([p])) for p in preds]

plt.figure(figsize=(10, 4))
plt.subplot(1, 2, 1)
plt.plot(preds, losses)
plt.axvline(x=0.5, color='gray', linestyle='--')
plt.xlabel('Predicted Probability (p)')
plt.ylabel('BCE Loss')
plt.title(f'BCE Loss for True Label = {y_true}')
plt.grid(True, alpha=0.3)

# 展示两类标签下的损失曲线
plt.subplot(1, 2, 2)
y_true_0_losses = [bce_loss(np.array([0]), np.array([p])) for p in preds]
y_true_1_losses = [bce_loss(np.array([1]), np.array([p])) for p in preds]
plt.plot(preds, y_true_0_losses, label='True label = 0', linewidth=2)
plt.plot(preds, y_true_1_losses, label='True label = 1', linewidth=2)
plt.xlabel('Predicted Probability (p)')
plt.ylabel('BCE Loss')
plt.title('BCE Loss: Both Labels')
plt.legend()
plt.grid(True, alpha=0.3)
plt.tight_layout()
plt.show()
```

**关键观察**：
- 当 $y=1$ 时，预测 $\hat{y} \to 1$ 损失趋近于 0，预测 $\hat{y} \to 0$ 损失趋近于无穷大。
- 当 $y=0$ 时，预测 $\hat{y} \to 0$ 损失趋近于 0，预测 $\hat{y} \to 1$ 损失趋近于无穷大。
- BCE 对错误的高置信度预测施加了极大的惩罚。

# 六、为什么不用 MSE 做分类？

如果将 MSE 用于二分类：

$$\mathcal{L}_{\text{MSE}} = \frac{1}{n}\sum_{i=1}^{n} (\sigma(z^{(i)}) - y^{(i)})^2$$

问题在于梯度：

$$\frac{\partial \mathcal{L}_{\text{MSE}}}{\partial z} = 2(\sigma(z) - y) \cdot \sigma(z)(1 - \sigma(z))$$

当 $\sigma(z)$ 接近 0 或 1 时，$\sigma(z)(1 - \sigma(z)) \to 0$，梯度消失，模型几乎无法学习。而 BCE 损失的梯度：

$$\frac{\partial \mathcal{L}_{\text{BCE}}}{\partial z} = \sigma(z) - y$$

这是一个线性差的形式，不会出现梯度消失的问题。因此 **BCE 是分类任务的标准选择**。

# 七、多分类扩展预览

对于 $K$ 类分类任务（$K > 2$），逻辑回归通过 **Softmax 函数** 扩展为多类逻辑回归（Multinomial Logistic Regression）：

$$P(y=k \mid \mathbf{x}) = \frac{e^{z_k}}{\sum_{j=1}^{K} e^{z_j}}, \quad z_k = \mathbf{w}_k^T \mathbf{x} + b_k$$

对应的损失函数为**交叉熵损失（Cross-Entropy Loss）**：

$$\mathcal{L}_{\text{CE}} = -\frac{1}{n}\sum_{i=1}^{n} \sum_{k=1}^{K} y_k^{(i)} \log \hat{y}_k^{(i)}$$

当 $K=2$ 时，Softmax + Cross-Entropy 退化为 Sigmoid + BCE（本质上等价，但数值形式略有不同）。我们将在后续课程中详细讨论 Softmax。

## 总结

| 概念 | 公式/说明 |
|------|-----------|
| 模型输出 | $\hat{y} = \sigma(\mathbf{w}^T\mathbf{x} + b)$ |
| Sigmoid | $\sigma(z) = 1/(1+e^{-z})$ |
| 决策边界 | $\mathbf{w}^T\mathbf{x} + b = 0$ |
| Log-Odds | $\ln\frac{p}{1-p} = \mathbf{w}^T\mathbf{x} + b$ |
| 损失函数 | $\mathcal{L} = -\frac{1}{n}\sum [y\log\hat{y} + (1-y)\log(1-\hat{y})]$ |
| 梯度 | $\frac{\partial\mathcal{L}}{\partial z} = \sigma(z) - y$ |
