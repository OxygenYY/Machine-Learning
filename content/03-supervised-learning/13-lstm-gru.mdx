## 为什么需要 LSTM？

标准 RNN 的梯度消失问题源于隐藏状态的连乘更新：$h_t = \tanh(W_h h_{t-1} + W_x x_t)$。每次更新都会"覆盖"旧信息，远距离依赖很难保留。

长短期记忆网络（Long Short-Term Memory, LSTM）引入**细胞状态（Cell State）** $c_t$，作为一条贯穿时间的"信息高速公路"。通过可学习的**门（gate）**控制信息的写入、遗忘和读取，梯度可以几乎无衰减地沿着细胞状态反向传播。

## LSTM 的四个门

LSTM 在每个时间步进行以下计算：

**遗忘门** $f_t$：决定丢弃细胞状态中的哪些旧信息
$$
f_t = \sigma(W_f \cdot [h_{t-1}, x_t] + b_f)
$$

**输入门** $i_t$：决定将哪些新信息写入细胞状态
$$
i_t = \sigma(W_i \cdot [h_{t-1}, x_t] + b_i)
$$

**候选细胞状态** $\tilde{c}_t$：生成新的候选信息
$$
\tilde{c}_t = \tanh(W_c \cdot [h_{t-1}, x_t] + b_c)
$$

**细胞状态更新**：遗忘旧信息 + 写入新信息
$$
c_t = f_t \odot c_{t-1} + i_t \odot \tilde{c}_t
$$

**输出门** $o_t$：决定输出哪些信息
$$
o_t = \sigma(W_o \cdot [h_{t-1}, x_t] + b_o)
$$

**隐藏状态**：基于过滤后的细胞状态
$$
h_t = o_t \odot \tanh(c_t)
$$

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class LSTMCell(nn.Module):
    """从零实现 LSTM 单元"""
    def __init__(self, input_size, hidden_size):
        super().__init__()
        # 将 4 个门的权重合并为一个大矩阵（效率更高）
        self.W = nn.Linear(input_size + hidden_size, 4 * hidden_size)

    def forward(self, x_t, state):
        """
        x_t: (batch, input_size)
        state: ((batch, hidden_size), (batch, hidden_size)) —— (h, c)
        """
        h_prev, c_prev = state
        # 拼接输入和上一隐藏状态
        combined = torch.cat([x_t, h_prev], dim=-1)
        gates = self.W(combined)  # (batch, 4 * hidden_size)

        # 分割 4 个门
        f, i, g, o = gates.chunk(4, dim=-1)
        f = torch.sigmoid(f)   # 遗忘门
        i = torch.sigmoid(i)   # 输入门
        g = torch.tanh(g)      # 候选细胞状态
        o = torch.sigmoid(o)   # 输出门

        # 细胞状态更新
        c = f * c_prev + i * g
        # 隐藏状态
        h = o * torch.tanh(c)
        return h, (h, c)


# 手写 LSTM 单步测试
batch, input_sz, hidden_sz = 4, 10, 20
cell = LSTMCell(input_sz, hidden_sz)
x_t = torch.randn(batch, input_sz)
h0 = torch.zeros(batch, hidden_sz)
c0 = torch.zeros(batch, hidden_sz)
h1, (h1_out, c1) = cell(x_t, (h0, c0))
print("LSTM cell 输出 h:", h1.shape)       # (4, 20)
print("LSTM cell 输出 c:", c1.shape)       # (4, 20)

# 验证细胞状态的线性更新带来的梯度优势
# c_t = f_t * c_{t-1} + i_t * g_t
# 当 f_t ≈ 1 时，梯度通过 c_{t-1} 的路径无衰减
print("\n关键洞察: 细胞状态是加法更新，而非乘法覆盖，梯度流动畅通")
```

## GRU：简化的门控单元

门控循环单元（Gated Recurrent Unit, GRU）将 LSTM 的三个门简化为两个门，合并了细胞状态和隐藏状态：

**重置门** $r_t$：控制忽略多少过去的信息
$$
r_t = \sigma(W_r \cdot [h_{t-1}, x_t] + b_r)
$$

**更新门** $z_t$：控制保留多少过去信息 vs 写入多少新信息
$$
z_t = \sigma(W_z \cdot [h_{t-1}, x_t] + b_z)
$$

**候选隐藏状态** $\tilde{h}_t$：
$$
\tilde{h}_t = \tanh(W_h \cdot [r_t \odot h_{t-1}, x_t] + b_h)
$$

**最终隐藏状态**：更新门控制新旧信息的插值
$$
h_t = (1 - z_t) \odot h_{t-1} + z_t \odot \tilde{h}_t
$$

```python
class GRUCell(nn.Module):
    """从零实现 GRU 单元"""
    def __init__(self, input_size, hidden_size):
        super().__init__()
        self.W_r = nn.Linear(input_size + hidden_size, hidden_size)  # 重置门
        self.W_z = nn.Linear(input_size + hidden_size, hidden_size)  # 更新门
        self.W_h = nn.Linear(input_size + hidden_size, hidden_size)  # 候选隐藏状态

    def forward(self, x_t, h_prev):
        combined = torch.cat([x_t, h_prev], dim=-1)
        r = torch.sigmoid(self.W_r(combined))     # 重置门
        z = torch.sigmoid(self.W_z(combined))     # 更新门

        combined_reset = torch.cat([x_t, r * h_prev], dim=-1)
        h_tilde = torch.tanh(self.W_h(combined_reset))  # 候选

        h = (1 - z) * h_prev + z * h_tilde        # 最终隐藏状态
        return h

# 简单测试
gru_cell = GRUCell(10, 20)
x_t = torch.randn(4, 10)
h_prev = torch.zeros(4, 20)
h = gru_cell(x_t, h_prev)
print("GRU cell 输出:", h.shape)  # (4, 20)
```

## LSTM vs GRU：选择指南

| 特性 | LSTM | GRU |
|------|------|-----|
| 门数量 | 3（遗忘、输入、输出） | 2（重置、更新） |
| 状态数量 | 2（h, c） | 1（h） |
| 参数量 | 较多（4 linear layers） | 较少（3 linear layers） |
| 训练速度 | 较慢 | 较快 |
| 长序列性能 | 稍好 | 相当（多数任务） |
| 适用场景 | 需要精确长距离建模 | 数据量有限或需要更快训练 |

**经验法则**：没有明确胜者。先在目标任务上快速实验两者；性能相近则优先选 GRU（更快、参数更少）；LSTM 在极长依赖任务上有轻微优势。

```python
lstm = nn.LSTM(
    input_size=128,
```

## 示例一：字符级语言模型（LSTM 版）

```python
class CharLSTM(nn.Module):
    """字符级语言模型 —— 用 LSTM 替代 RNN"""
    def __init__(self, vocab_size, embed_dim=128, hidden_size=512,
                 num_layers=3, dropout=0.4):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embed_dim)
        self.lstm = nn.LSTM(embed_dim, hidden_size, num_layers,
                            batch_first=True, dropout=dropout)
        self.fc = nn.Linear(hidden_size, vocab_size)

    def forward(self, x, state=None):
        x = self.embedding(x)
        out, state = self.lstm(x, state)
        logits = self.fc(out)
        return logits, state

    def generate(self, seed, char_to_idx, idx_to_char,
                 length=200, temperature=0.8, device='cpu'):
        self.eval()
        self.to(device)
        idx = torch.tensor([[char_to_idx[seed]]], device=device)
        state = None
        result = [seed]

        with torch.no_grad():
            for _ in range(length):
                logits, state = self(idx, state)
                probs = F.softmax(logits.squeeze() / temperature, dim=-1)
                next_idx = torch.multinomial(probs, 1).item()
                result.append(idx_to_char[next_idx])
                idx = torch.tensor([[next_idx]], device=device)

        return ''.join(result)
```

## 示例二：双向 LSTM 情感分类

情感分析是 NLP 的经典任务。双向 LSTM 能够同时捕捉上下文信息（修饰词可能在目标词之前或之后），非常适合序列分类。

```python
class SentimentBiLSTM(nn.Module):
    """双向 LSTM 用于文本情感分类（正面/负面）"""
    def __init__(self, vocab_size, embed_dim=300, hidden_size=256,
                 num_layers=2, num_classes=2, dropout=0.5,
                 pad_idx=0, pretrained_embeddings=None):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embed_dim,
                                       padding_idx=pad_idx)
        if pretrained_embeddings is not None:
            self.embedding.weight.data.copy_(pretrained_embeddings)
            self.embedding.weight.requires_grad = False  # 冻结预训练词向量

        self.lstm = nn.LSTM(embed_dim, hidden_size, num_layers,
                            batch_first=True, bidirectional=True,
                            dropout=dropout if num_layers > 1 else 0)
        # 双向 LSTM 输出维度为 hidden_size * 2
        self.attention = nn.Sequential(
            nn.Linear(hidden_size * 2, 1),
        )
        self.classifier = nn.Sequential(
            nn.Linear(hidden_size * 2, 128),
            nn.ReLU(),
            nn.Dropout(dropout),
            nn.Linear(128, num_classes),
        )

    def forward(self, x, lengths):
        """
        x: (batch, seq_len) —— token 索引
        lengths: (batch,) —— 每个样本的实际长度
        """
        embedded = self.embedding(x)  # (batch, seq_len, embed_dim)

        # pack_padded_sequence 跳过 padding，加速计算
        packed = nn.utils.rnn.pack_padded_sequence(
            embedded, lengths.cpu(), batch_first=True, enforce_sorted=False)
        packed_out, (h_n, _) = self.lstm(packed)
        out, _ = nn.utils.rnn.pad_packed_sequence(packed_out, batch_first=True)

        # 方法1: 使用最后一个时间步的输出（取双向拼接）
        # 由于 pack_padded_sequence，需要选择实际最后一个位置
        idx = (lengths - 1).unsqueeze(1).unsqueeze(2).to(x.device)
        idx = idx.expand(-1, 1, out.size(2))
        last_output = out.gather(1, idx).squeeze(1)

        # 方法2 (备选): 使用双向隐藏状态拼接
        # forward_hidden = h_n[-2]  # 正向最后一层
        # backward_hidden = h_n[-1] # 反向最后一层
        # combined = torch.cat([forward_hidden, backward_hidden], dim=-1)

        return self.classifier(last_output)

# 使用示例
vocab_size = 30000
model = SentimentBiLSTM(vocab_size)
batch_x = torch.randint(0, vocab_size, (32, 50))   # 32 条评论，每条约 50 词
batch_lengths = torch.randint(10, 51, (32,))       # 每条评论的实际长度
logits = model(batch_x, batch_lengths)
print("情感分类 logits 形状:", logits.shape)  # (32, 2)
```

## 堆叠/深层 LSTM

多个 LSTM 层堆叠在一起，底层学习简单的时序模式，高层学习更抽象的组合模式。

```python
class StackedLSTM(nn.Module):
    """堆叠 LSTM —— 每层输出作为下一层输入"""
    def __init__(self, input_size, hidden_size, num_layers=3, num_classes=10):
        super().__init__()
        self.lstm = nn.LSTM(input_size, hidden_size, num_layers,
                            batch_first=True, dropout=0.3)
        self.fc = nn.Linear(hidden_size, num_classes)

    def forward(self, x):
        # x: (batch, seq_len, input_size)
        out, _ = self.lstm(x)
        # 取最后一层的最后一个时间步
        return self.fc(out[:, -1, :])

# 参数规模对比
input_sz, hidden_sz = 128, 256
for num_l in [1, 2, 3]:
    m = StackedLSTM(input_sz, hidden_sz, num_l)
    params = sum(p.numel() for p in m.parameters())
    print(f"num_layers={num_l}: {params:,} 参数")

print("\n关键提示: 增加 LSTM 层数会显著增加参数量和训练时间，"
      "通常 2-3 层就足够了，更深需要残差连接辅助")
```

## 训练技巧总结

1. **梯度裁剪**：`torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=5.0)`——对 LSTM 同样重要，防止偶发的梯度爆炸。

2. **初始化**：将遗忘门的偏置初始化为正数（如 1.0），使初始状态下倾向于保留信息：
   ```python
   for name, param in lstm.named_parameters():
       if 'bias_hh' in name:
           n = param.size(0)
           param.data[n//4:n//2].fill_(1.0)  # 遗忘门偏置 = 1
   ```

3. **pack_padded_sequence**：处理变长序列时，先按长度降序排列，打包后送入 LSTM/GRU，可以跳过 padding 计算，显著加速。

4. **Dropout**：LSTM/GRU 的 dropout 作用于层间（而非时间步内），时间步内的 dropout 需要用变分 dropout 等特殊技术。
