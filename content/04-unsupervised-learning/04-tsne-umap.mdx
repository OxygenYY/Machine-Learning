# t-SNE 与 UMAP 非线性降维

PCA 虽然高效，但它只能发现线性的数据结构。真实的机器学习数据往往分布在高度非线性的流形上——想象一张卷曲的纸上的点，在三维空间中呈曲面，但其本质结构是二维的。t-SNE 和 UMAP 就是解决这一问题的利器。

## t-SNE：t 分布随机邻域嵌入

t-SNE（t-distributed Stochastic Neighbor Embedding）由 van der Maaten 和 Hinton 于 2008 年提出，核心思想是：**在高维空间中邻近的点，在低维空间中也应该邻近**。

### t-SNE 的核心思想

t-SNE 分为两步：

**第一步**：在高维空间中，用条件概率 $p_{j|i}$ 表示点 $x_j$ 是点 $x_i$ 邻居的概率。使用以 $x_i$ 为中心的高斯分布：

$$p_{j|i} = \frac{\exp(-\|x_i - x_j\|^2 / 2\sigma_i^2)}{\sum_{k \neq i} \exp(-\|x_i - x_k\|^2 / 2\sigma_i^2)}, \quad p_{i|i} = 0$$

对称化得到联合概率：

$$p_{ij} = \frac{p_{j|i} + p_{i|j}}{2n}$$

$\sigma_i$ 通过困惑度（perplexity）间接控制：令每个点的高斯分布具有由用户指定的困惑度，等价于 $\text{Perp}(P_i) = 2^{H(P_i)}$，其中 $H(P_i)$ 为香农熵。困惑度可以理解为对每个点有效邻域大小的平滑度量。

**第二步**：在低维空间中，用 Student-t 分布（自由度为 1）表示相似度：

$$q_{ij} = \frac{(1 + \|y_i - y_j\|^2)^{-1}}{\sum_{k \neq l} (1 + \|y_k - y_l\|^2)^{-1}}, \quad q_{ii} = 0$$

使用 t 分布（而非高斯）的关键原因：t 分布有更重的尾部，这允许中距离的点在低维空间有合理的距离，解决了"拥挤问题"（crowding problem）。

**优化目标**：最小化 $P$ 和 $Q$ 之间的 KL 散度：

$$\mathcal{L} = \text{KL}(P \| Q) = \sum_{i \neq j} p_{ij} \log \frac{p_{ij}}{q_{ij}}$$

使用梯度下降优化低维嵌入 $y_1, \ldots, y_n$。

### 困惑度（Perplexity）的意义

困惑度是 t-SNE 最重要的超参数，典型取值为 5 到 50：

- **较小的困惑度**（5-10）：关注非常局部的结构，会看到更多小的子簇
- **较大的困惑度**（30-50）：关注更全局的结构，簇更大更松散

建议：对 perplexity 在 $[5, 10, 20, 30, 50]$ 之间多次运行，观察结果的稳定性。

### t-SNE 实战

```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.datasets import fetch_openml
from sklearn.manifold import TSNE
from sklearn.preprocessing import StandardScaler
import torch

def tsne_mnist_viz(n_samples=3000, perplexity=30):
    """用 t-SNE 可视化 MNIST 子集"""
    # 加载数据
    mnist = fetch_openml('mnist_784', version=1, as_frame=False,
                         parser='auto')
    X = mnist.data[:n_samples].astype(np.float32)
    y = mnist.target[:n_samples].astype(int)

    # 标准化
    X_scaled = StandardScaler().fit_transform(X)

    # t-SNE 降维
    print(f"正在对 {n_samples} 个样本运行 t-SNE (perplexity={perplexity})...")
    tsne = TSNE(n_components=2, perplexity=perplexity,
                random_state=42, n_iter=1000, verbose=0)
    Z_tsne = tsne.fit_transform(X_scaled)
    print("t-SNE 完成")

    # 可视化
    fig, ax = plt.subplots(figsize=(10, 8))
    colors = plt.cm.tab10(np.linspace(0, 1, 10))
    for digit in range(10):
        mask = y == digit
        ax.scatter(Z_tsne[mask, 0], Z_tsne[mask, 1],
                   c=[colors[digit]], label=str(digit),
                   s=8, alpha=0.6)
    ax.set_title(f't-SNE 可视化 (perplexity={perplexity}, n={n_samples})')
    ax.legend(markerscale=3, loc='upper right')
    plt.show()

    return Z_tsne

def compare_perplexities(X, y, perplexities=[5, 15, 30, 50]):
    """对比不同困惑度的 t-SNE 结果"""
    fig, axes = plt.subplots(2, 2, figsize=(14, 12))
    for ax, perp in zip(axes.flat, perplexities):
        tsne = TSNE(n_components=2, perplexity=perp,
                    random_state=42, n_iter=1000)
        Z = tsne.fit_transform(X)
        scatter = ax.scatter(Z[:, 0], Z[:, 1],
                             c=y, cmap='tab10', s=5, alpha=0.6)
        ax.set_title(f'perplexity = {perp}')
        ax.set_xticks([])
        ax.set_yticks([])
    plt.colorbar(scatter, ax=axes.flat, label='数字')
    plt.suptitle('不同困惑度下的 t-SNE 结果对比')
    plt.tight_layout()
    plt.show()
```

## UMAP：统一流形近似与投影

UMAP（Uniform Manifold Approximation and Projection，McInnes et al., 2018）是较新的降维工具，在很多方面优于 t-SNE。

### UMAP vs t-SNE

| 特性 | t-SNE | UMAP |
|------|-------|------|
| 速度 | 较慢，O(n^2) | 较快，可处理百万级数据 |
| 全局结构 | 保留较弱 | 更好地保留全局距离关系 |
| 簇的大小 | 不可信 | 相对更可信 |
| 可扩展性 | 差 | 好，支持新数据的变换 |
| 参数 | perplexity | n_neighbors, min_dist |
| 输出维度 | 通常 2D-3D | 可降到任意维度 |

### UMAP 关键参数

- **n_neighbors**：控制局部与全局结构的平衡。较小的值（5-15）关注局部细节，较大的值（50-200）关注全局结构
- **min_dist**：低维空间中点之间的最小距离。较小的值产生更紧密的簇，较大的值产生更松散的分布
- **metric**：距离度量，默认 `'euclidean'`

### UMAP 实战

```python
import umap

def umap_embedding_pipeline(X, n_neighbors=15, min_dist=0.1,
                            n_components=2, metric='euclidean'):
    """完整的 UMAP 降维流水线"""
    # UMAP 降维
    reducer = umap.UMAP(
        n_neighbors=n_neighbors,
        min_dist=min_dist,
        n_components=n_components,
        metric=metric,
        random_state=42,
        n_jobs=-1
    )
    embedding = reducer.fit_transform(X)

    print(f"输入形状: {X.shape} -> 输出形状: {embedding.shape}")
    return embedding, reducer

def compare_umap_params(X, y):
    """对比不同 UMAP 参数的效果"""
    param_combos = [
        {'n_neighbors': 5, 'min_dist': 0.01},
        {'n_neighbors': 5, 'min_dist': 0.5},
        {'n_neighbors': 50, 'min_dist': 0.01},
        {'n_neighbors': 50, 'min_dist': 0.5},
    ]

    fig, axes = plt.subplots(2, 2, figsize=(14, 12))
    for ax, params in zip(axes.flat, param_combos):
        reducer = umap.UMAP(**params, random_state=42)
        Z = reducer.fit_transform(X)
        ax.scatter(Z[:, 0], Z[:, 1], c=y, cmap='tab10', s=3, alpha=0.6)
        ax.set_title(f"n_neighbors={params['n_neighbors']}, "
                     f"min_dist={params['min_dist']}")
        ax.set_xticks([])
        ax.set_yticks([])
    plt.suptitle('不同 UMAP 参数效果对比')
    plt.tight_layout()
    plt.show()
```

## 三种方法综合对比

```python
from sklearn.decomposition import PCA

def compare_all_dimensionality_reduction(X, y, n_samples=3000):
    """在同一数据上对比 PCA、t-SNE、UMAP"""
    fig, axes = plt.subplots(1, 3, figsize=(18, 5.5))

    # PCA
    pca = PCA(n_components=2, random_state=42)
    Z_pca = pca.fit_transform(X)
    axes[0].scatter(Z_pca[:, 0], Z_pca[:, 1],
                    c=y, cmap='tab10', s=5, alpha=0.7)
    evr = pca.explained_variance_ratio_
    axes[0].set_title(f'PCA ({evr[0]*100:.1f}% + {evr[1]*100:.1f}% 方差)')

    # t-SNE
    tsne = TSNE(n_components=2, perplexity=30, random_state=42, n_iter=1000)
    Z_tsne = tsne.fit_transform(X)
    axes[1].scatter(Z_tsne[:, 0], Z_tsne[:, 1],
                    c=y, cmap='tab10', s=5, alpha=0.7)
    axes[1].set_title('t-SNE (perplexity=30)')

    # UMAP
    reducer = umap.UMAP(n_neighbors=15, min_dist=0.1, random_state=42)
    Z_umap = reducer.fit_transform(X)
    axes[2].scatter(Z_umap[:, 0], Z_umap[:, 1],
                    c=y, cmap='tab10', s=5, alpha=0.7)
    axes[2].set_title('UMAP (n_neighbors=15)')

    for ax in axes:
        ax.set_xticks([])
        ax.set_yticks([])

    plt.suptitle('PCA vs t-SNE vs UMAP 对比', fontsize=14)
    plt.tight_layout()
    plt.show()
```

## t-SNE 常见陷阱

1. **簇的大小不代表聚类大小**：t-SNE 倾向于将所有簇压缩到大致相同的密度，因此图中簇的大小不代表实际数据量
2. **簇间距离不代表相似度**：两个簇在 t-SNE 图中的距离不直接反映它们的实际相似度
3. **不要用 t-SNE 输出来做聚类**：t-SNE 不保留密度信息，用它判断有多少个簇是不可靠的
4. **随机种子影响较大**：不同随机种子可能产生差异显著的布局，始终固定 `random_state`
5. **困惑度至关重要**：太小的困惑度会产生虚假的结构噪声

## 实践建议

- **探索数据时优先用 PCA**，快速获得全局概览
- **发布可视化时用 UMAP**，速度更快且能更好地保留全局结构
- **需要突出局部簇结构时用 t-SNE**
- **始终尝试多个参数组合**，确保洞察不是特定参数的人为产物
- **先在 PCA 上选 k 再在 t-SNE/UMAP 上投影**：对高维数据，先 PCA 降维到 ~50 维（保留大部分方差），再输入 t-SNE/UMAP，大大提高速度且几乎不影响效果

## 小结

t-SNE 和 UMAP 是非线性降维的双璧。UMAP 由于速度、可扩展性和更好的全局结构保留能力，正在越来越多的场景中取代 t-SNE。但理解两者的原理与参数含义，能帮助你做出明智的选择。牢记：降维可视化是探索性工具，用于发现模式和提出假设，而非严格的统计检验。下一课我们将学习自编码器——用神经网络进行降维。
