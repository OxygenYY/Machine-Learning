# 一、什么是迁移学习？

迁移学习（Transfer Learning）的核心思想很简单：**将一个任务上学到的知识，迁移到另一个相关但不同的任务上**。在深度学习中，这通常意味着使用在大规模数据集（如 ImageNet）上预训练的模型，将其应用到你的小规模自定义任务上。

形式化地说，给定源域 $\mathcal{D}_S$ 和源任务 $\mathcal{T}_S$，目标域 $\mathcal{D}_T$ 和目标任任务 $\mathcal{T}_T$，迁移学习的目标是利用从 $(\mathcal{D}_S, \mathcal{T}_S)$ 学到的知识来提升目标预测函数 $f_T(\cdot)$ 的学习效果。

# 二、为什么迁移学习有效？

深度卷积网络中，不同层学习到的特征具有层级性：

- **浅层（前几层）**：学习通用的低级特征——边缘、颜色、纹理、角落。这些特征几乎对所有视觉任务都有用。
- **中层**：学习更复杂的模式——形状、部件、重复结构。
- **深层（最后几层）**：学习高度任务特定的特征——人脸、车轮、特定物体类别。

浅层特征具有高度的**通用性（generality）**，这意味着在 ImageNet 上学到的边缘检测器，也可直接在医学影像或卫星图像中使用。这解释了为什么迁移学习如此强大——模型不必从头学习这些基础特征。

# 三、两种主要的迁移学习方式

## 特征提取（Feature Extraction）

冻结预训练模型的所有卷积层（作为固定的特征提取器），只训练新添加的分类头：

```python
import torch
import torch.nn as nn
import torchvision.models as models

# 加载预训练的 ResNet18
model = models.resnet18(weights=models.ResNet18_Weights.IMAGENET1K_V1)

# 冻结所有卷积层参数
for param in model.parameters():
    param.requires_grad = False

# 替换最后的全连接分类层
num_features = model.fc.in_features
model.fc = nn.Sequential(
    nn.Linear(num_features, 256),
    nn.ReLU(),
    nn.Dropout(0.5),
    nn.Linear(256, 10)  # 假设10个自定义类别
)

# 只有新添加的 fc 层参数需要梯度
trainable_params = sum(p.numel() for p in model.parameters() if p.requires_grad)
total_params = sum(p.numel() for p in model.parameters())
print(f"可训练参数: {trainable_params:,} / 总参数: {total_params:,}")
```

## 微调（Fine-tuning）

解冻预训练模型的部分或全部层，以较小的学习率与新分类头一起训练：

```python
# 加载预训练模型
model = models.resnet18(weights=models.ResNet18_Weights.IMAGENET1K_V1)

# 替换分类头
model.fc = nn.Linear(model.fc.in_features, 10)

# 全部参数可训练，但使用不同的学习率分组
optimizer = torch.optim.SGD([
    {'params': model.fc.parameters(), 'lr': 1e-3},           # 新分类头：大学习率
    {'params': model.layer4.parameters(), 'lr': 1e-4},       # 最后卷积层：中等学习率
    {'params': model.layer3.parameters(), 'lr': 1e-5},       # 倒数第二层：更小
    {'params': model.layer2.parameters(), 'lr': 1e-6},       # 浅层：最小
], momentum=0.9, weight_decay=1e-4)

print("使用了判别式学习率：浅层小，深层大")
```

# 四、层冻结策略

有三种常见的层冻结策略值得掌握：

**1. 全部冻结 → 特征提取**：只训练新分类头。适合目标数据集很小（<1000 张图）、且与预训练数据相似的情况。

**2. 渐进式解冻（Progressive Unfreezing）**：从最后一层开始，逐层向前解冻。每次解冻一层，训练几轮，再解冻前一层：

```python
def progressive_unfreeze(model, epoch, unfreeze_every=3):
    """每 unfreeze_every 个 epoch 解冻一个新的层组"""
    layer_groups = [model.layer4, model.layer3, model.layer2, model.layer1]
    num_unfrozen = min(epoch // unfreeze_every, len(layer_groups))

    # 先冻结所有
    for layer in layer_groups:
        for param in layer.parameters():
            param.requires_grad = False

    # 从后往前解冻
    for i in range(num_unfrozen):
        idx = len(layer_groups) - 1 - i
        for param in layer_groups[idx].parameters():
            param.requires_grad = True

    print(f"Epoch {epoch}: 已解冻 {num_unfrozen} 个层组")

# 在训练循环中调用（示例）
# for epoch in range(num_epochs):
#     progressive_unfreeze(model, epoch, unfreeze_every=3)
```

**3. 判别式学习率（Discriminative Learning Rates）**：不同层使用不同的学习率。如前面代码所示，浅层使用较小的学习率（因为特征已经很好），深层和新层使用较大的学习率。

# 六、何时用特征提取？何时用微调？

这是一个关键的决策问题。核心考量两个因素：**数据集大小**和**与预训练数据的相似度**。

| 场景 | 目标数据集大小 | 与 ImageNet 相似度 | 推荐策略 |
|------|---------------|-------------------|---------|
| A | 小（<1K） | 高 | 特征提取（训练分类头） |
| B | 小（<1K） | 低 | 特征提取 + 更多数据增强 |
| C | 大（>10K） | 高 | 微调全部层（小学习率） |
| D | 大（>10K） | 低 | 微调（或从头训练一部分） |

一般原则：数据越少，应冻结的层越多；数据越不相似，越需要解开更多层进行微调。

# 九、迁移学习的最佳实践

1. **数据预处理必须匹配预训练模型**：ImageNet 模型的归一化均值和标准差是固定的，必须使用 `mean=[0.485, 0.456, 0.406]` 和 `std=[0.229, 0.224, 0.225]`。输入尺寸也应匹配（通常 224×224）。

2. **从小学习率开始**：微调时学习率通常比从头训练小 10~100 倍。典型值：SGD 的 lr=1e-3 ~ 1e-4，Adam 的 lr=1e-4 ~ 1e-5。

3. **使用学习率预热（Warmup）**：训练开始时，学习率从很小线性增长到目标值，避免初期参数被大幅破坏。

4. **监控过拟合**：当目标数据集很小时，微调容易过拟合。使用强正则化（Dropout, Weight Decay）并尽早验证。

5. **考虑使用预训练模型的其他部分**：不仅可以使用分类模型的主干网络，目标检测、分割等任务也有丰富的预训练模型生态。

## 总结

迁移学习是现代深度学习的核心范式之一。在大模型时代，几乎没有人从头训练视觉或语言模型——从预训练权重出发，仅在目标数据上微调，既节省计算资源，又能在小数据量下获得优异性能。理解特征提取与微调的区别、掌握层冻结策略和判别式学习率，是每个深度学习实践者的必备技能。
